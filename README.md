Описание проекта:

В работе проведен полный цикл анализа данных интернет-магазина: от очистки и разведочного анализа (ETL и EDA) до сегментации клиентов и прогнозирования возвратов заказов с помощью машинного обучения.


Структура репозитория:

Ссылка https://github.com/mtyrion-coder/E-Commerce-Analytics

README.md — описание проекта и структуры репозитория.

Итоговая_работа.docx — текст аттестационной работы.

Analysis_Ecommerce.ipynb — Jupyter Notebook с кодом проекта (ETL, EDA, ABC-XYZ, RFM, ML).

input/ — папка с исходными датасетом (ecommerce_orders.csv).

output/ — папка с результатами работы: очищенный датасет, таблицы ABC-XYZ и RFM, датасет для дашборда BI-системы и графики (Рис. 1 – Рис. 6 в формате PNG).


Запуск:

Код написан с учетом различных вариантов размещения исходных файлов и является устойчивым к изменениям структуры папок.

1. Для запуска кода необходимо два файла: Analysis_Ecommerce.ipynb и ecommerce_orders.csv.
2. Исходный датасет ecommerce_orders.csv должен находиться в папке input, расположенной в той же директории, что и файл блокнота Analysis_Ecommerce.ipynb или просто рядом с блокнотом.
3. Откройте Analysis_Ecommerce.ipynb в любой среде Python (локально в Jupyter Notebook или в облаке).
4. Нажмите Run All (Выполнить всё).

Все сгенерированные файлы (очищенный датасет, таблицы ABC-XYZ и RFM, датасет для BI-системы, а также графики Figure_1 – Figure_6) автоматически сохраняются в папку output, которая создается рядом с файлом блокнота. 


Инструменты и технологии:

Python (Pandas, NumPy, Matplotlib, Seaborn).
Машинное обучение (Scikit-learn, XGBoost, Statsmodels).
Yandex DataLens (построение интерактивного дашборда).


Ключевые результаты:

1. Сформирован очищенный датасет (10 026 записей после удаления дубликатов).
2. Выявлены лидеры по выручке: Electronics, Clothing, Home & Kitchen.
3. Средний уровень возвратов составил 17.34% (выявлен дисбаланс классов).
4. Проведена сегментация: выделены «Чемпионы», «Лояльные» и группа «Под угрозой».
5. Обучены 3 модели ML. Наилучший результат показала логистическая регрессия (ROC-AUC = 0.6598, F1-score = 0.36).
